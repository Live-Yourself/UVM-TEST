     DRC of Place and Route test cases:
     -------------------------------------
    
       o Orientation & Placement of Triple well Specific cells
   
         All the cells in this library has DeepNwell Layer (DNW)
         Following Placement is needed to avoid DRC errors needed to have
         DNW shape and Nwell shape in the block level.
      
     	 - ENDCAPTIE11_A7TR cell to be placed in both left and right edges of the Block 
           (with topmost row and left side without any flipping.)
         - Top-most row to be placed with no vertical Flipping.
       	   ie., VDD rail to face the North Orientation.
     	 - Bottom-most row to be placed with vertical Flipping.
           ie., VDD rail to face the South Orientation.   


 
Known Problems and Solutions
----------------------------
This section describes known problems and work-arounds as of the release
date of this library.

    o All the cell will flag for following DRC
      (SMIC has agreed to relax these rules in the upcoming DRC deck)
     		DNW_9 : Minimum space from a NW edge to a N+AA outside surrounding NW when DNW is implemented is 0.5
		
    o Few cells would fail for following rules 
      (SMIC has agreed to update these rules in the upcoming DRC deck)
    		PW_1 : Minimum width of an PW region is 0.86um.

    o Few cells would fail for following rules (Metal SLOT rules)
      (SMIC has agreed to update these rules in the upcoming DRC deck)
		 
		SLOT_1_a  : Minimum slot dimension for each metal layers is 2.0
		SLOT_2_a  : Minimum slot enclosure by metal is 5.0
		SLOT_3a_a : Minimum space between slots is 2.0


    o The following warning message will be reported when the Liberty files are read into RTL Compiler: 
        - Warning : Improperly defined 'leakage_power' group. [LBR-150]:   
                     The 'related_pg_pin' attribute value 'VDD*' in 'leakage_power' group
        - Cadence has fixed this issue in 9.1.100 release
          Cadence has confirmed that this warning will not have any impact on the calculation
	  of leakage power and no impact on reporting power.For leakage power calculations and
	  effect on RC by this Warning, please see if the pg_pin group is defined later than its 
	  usage, then warning can be ignored.
	
    o Encounter could flag the following Warning for the MXI2D* family cells.

         Warning :   **WARN: (SOCLF-200):    Pin 'A' in macro 'MXI2D' has no
                     ANTENNAGATEAREA attribute defined.
                     For any non-power/ground input or inout pin, The attribute should be
                     defined if any area ratio antenna attribute is defined on any layer.

        The MXI2D* family of cells do not have the ANTENNAGATEAREA defined for pin A
        and B. For these cells, these pins are not gate inputs; they are diffusion
        inputs. Therefore, no gate area exists and ANTENNAGATEAREA cannot be defined.
        However ANTENNADIFFAREA is defined for these pins.
